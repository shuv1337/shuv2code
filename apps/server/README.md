# shuv2code

Local-first coding agent server and CLI for the shuv2code monorepo.

## Install

```bash
npm install -g shuv2code
# or
npx shuv2code
```

The package exposes two binaries:

- `shuv2code`
- `s2c` (short alias)

## Channels

| npm dist-tag | Versions                                      |
| ------------ | --------------------------------------------- |
| `latest`     | Stable releases only (`0.1.0`)                |
| `next`       | Named prereleases (`0.1.0-alpha.1`, beta, rc) |
| `nightly`    | Nightly builds (`0.1.0-nightly.YYYYMMDD.N`)   |

Prefer `npx shuv2code@next` while the product is in alpha.
