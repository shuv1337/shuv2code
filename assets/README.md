# shuv2code brand assets

`assets/brand/shuv2code-devil-terminal.svg` is the canonical mark. Channel
colors and product identity live in `brand/shuv2code.brand.json`.

Run `vp run icons:export` on Linux, macOS, or Windows to generate every tracked
PNG and ICO used by the web, desktop, iOS, Android, and release packages. Run
`vp run icons:check` in CI to prove the checked-in exports match those sources.
The generator uses Sharp and the repository's ICO encoder, so native design
tools are not required.

The three `.icon` projects remain checked-in for Apple's Icon Composer workflow:

- `prod/app-icon.icon`
- `nightly/app-icon.icon`
- `dev/app-icon.icon`

Their vector layer uses the same mark and channel colors. Static Apple and
desktop exports are still generated by the portable repository script so they
remain reproducible on every development and CI host.
